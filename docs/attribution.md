# Research Attribution and Public-Release Boundary

This repository is an independent research project developed with reference to previously published model-driven deep-learning research on hybrid beamforming under imperfect CSI and outage constraints.

The referenced publication serves as scientific background and a baseline for comparison. This repository does not redistribute the referenced authors' source code, datasets, checkpoints, figures, tables, manuscript text, or other copyrighted research materials.

Public releases are limited to independently developed project documentation, implementations approved for release, independently generated results and figures, and reproducibility metadata whose redistribution status is clear.

A bibliographic reference to the scientific baseline should be provided in the project References section. Citation of a publication does not imply affiliation, endorsement, or joint authorship.

## Release rule

If ownership, provenance, or redistribution status of a file is uncertain, do not place it in the public repository until it has been reviewed.
